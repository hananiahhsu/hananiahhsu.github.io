    <h2>My field of work</h2>
    <p>I work across C++ systems engineering, CAD architecture, boundary representation, parametric modeling, engineering algorithms, and BIM/IFC information workflows.</p>
    <p>My current work includes the SolidDesigner/Alice platform and industrial software connected to <a href="https://www.tusyndon.com" target="_blank" rel="noopener">Tusyndon</a>. The common thread is the same: represent engineering meaning correctly, compute with it reliably, and give professionals an interaction model they can trust.</p>

    <h2>Why mathematics belongs here</h2>
    <p>Reliable CAD and simulation software depends on more than implementation technique. Analysis, measure, function spaces, approximation, and numerical reasoning provide the language for understanding convergence, error, stability, and representation. My mathematics writing is part of the engineering practice, not a separate hobby.</p>

    <h2>How I approach software</h2>
    <p>I prefer explicit responsibilities, domain-correct models, stable object identity, well-defined transactions, predictable API contracts, and performance decisions supported by measurement. For CAD features, product behavior and implementation architecture must agree from initial creation through every later edit.</p>
